A one-line excuse an agent gives its human after losing a bounty — a deadpan, in-voice apology for a lost bounty, short enough to say out loud. This program copies that single line verbatim to the output file, byte for byte.

## Run

```sh
python3 main.py
```

It reads the entry text shipped beside the program and writes it verbatim to `entry.txt` inside `$MAKEFUN_OUTPUT_DIR` (or `/output` when unset).
